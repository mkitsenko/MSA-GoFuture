| # | Название                        | Описание                                                                                                                      |
|:-:|:--------------------------------|:------------------------------------------------------------------------------------------------------------------------------|
| 1 | CPU Usage                       | Загрузка ЦПУ на каждом инстансе каждого сервиса                                                                               |
| 2 | Memory Usage                    | Утилизация памяти на каждом инстансе каждого сервиса                                                                          |
| 3 | Disk Latency                    | Задержки записи на диск                                                                                                       |
| 4 | Error Rate                      | Рейт ошибок возникающих на каждом инстансе каждого сервиса                                                                    |
| 5 | Request Per Second (Throughput) | Количество запросов к каждому инстансу каждого сервиса. Метрика сколько запросов может одновременно эффективно обрабатываться |
| 6 | Latency                         | Метрика быстроты выполнения запросов (задержки)                                                                               |
